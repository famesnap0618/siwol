# 시월 검사 — 부모 양육 태도 온라인 검사

『양육의 정석』 온라인 점검. 80문항(8영역 × 10문항, 5점 척도)으로 **우리 집 양육 태도 지도**를 그리고, 배우자와 두 지도를 겹쳐 봅니다.

블루돌핀 놀이기질 검사와 같은 구조(로그인 없음 · 서버 저장 없음 · 결과는 URL로 복원)를 따르되, 결과 화면과 판정 방식은 다릅니다.

| | 블루돌핀 | 시월 검사 |
|---|---|---|
| 문항 | 28문항 · 4점 척도 | 80문항 · 5점 척도, 영역 합계 10~50 |
| 판정 | 대표/보조 기질 유형 | 유형 없음. 영역별 `부족 / 이상적 / 넘침` 밴드 (영역마다 컷오프 다름) |
| 그래프 | 4차원 막대 | 8축 방사형 지도 + 영역별 적정 범위 띠 |
| 결과 본문 | 기질 해설, 맞춤 놀이 4개 | 영역 카드 8개, 조합 카드 1개(112쌍 + 전체 모양 4개), 책 연결 |
| 부부 | 없음 | 배우자 링크 → 두 지도 겹쳐 보기 + 차이 해석(24개) |

## 실행

빌드 과정이 없는 정적 사이트입니다. **`index.html`을 더블클릭하면 검사지가 바로 열립니다** (서버 불필요). 검사를 마치면 자동으로 `result.html`(결과)로 넘어갑니다.

문구를 고칠 때는 `data/*.json`을 수정한 뒤 아래 명령으로 `assets/js/data.js`를 다시 만들어야 화면에 반영됩니다.

```bash
npm run data
```

```bash
npm test
```

## 서버 모드 (가족 코드 · 부부 연결 · 알림)

설계는 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). `data/config.json`에 Supabase 주소와 공개 키를 넣으면 서버 모드로 바뀌고, 비어 있으면 URL 방식으로 동작합니다.

Supabase 없이 내 컴퓨터에서 서버 모드를 시험하려면:

```bash
npm install
```

```bash
npm run dev
```

→ http://localhost:5174

## 결과 URL (확정 후 변경 금지 — 공유된 링크가 깨집니다)

```
result.html?r=m&d=20261021&s=24-31-40-30-38-28-37-22
result.html?r=f&d=20261022&s=...&pr=m&pd=20261021&ps=...   ← 배우자 점수 포함
index.html?ir=m&id=20261021&is=...                         ← 배우자 초대 링크
```

- `r` 역할 (`m` 엄마 / `f` 아빠 / `o` 기타 양육자), `d` 검사일, `s` 영역 점수 8개 (애정·설득·성과·개입·제재·감시·암묵·일관 순)
- `p*` 배우자, `i*` 초대한 사람. 값이 잘못되면 "결과를 불러올 수 없습니다" 안내

## 판정 규칙 (구현 기준)

- **밴드**: 영역별 컷오프(`areas.json`의 `cut`). 경계 거리 = 적정 범위 끝에서 몇 점 벗어났는지
- **조합 카드**: 적정 밖 두 영역의 짝 중 조건이 맞는 것 → 우선순위 단계 낮은 것 → 두 영역 경계 거리 합이 큰 것 → 표 번호가 작은 것. **일관성↑ 짝은 제외**. 4단계뿐이면 제목을 "함께 보면 좋은 두 영역"으로
- **전체 모양**: 적정 밖 0개 → A, 높은 쪽 4개 이상 → B, 낮은 쪽 4개 이상 → C, 적정 밖 5개 이상 → D. 짝 카드가 있으면 그 아래 "지도 전체로 보면" 보조 문구로 표시
- **먼저 볼 영역**: 짝도 모양도 없을 때(적정 밖 1개 등) 가장 멀리 벗어난 영역
- **부부 차이**: 밴드가 다른 영역 중 점수 차가 가장 큰 영역 1개 (동점이면 번호가 작은 쪽). 높음·적정 → A, 낮음·적정 → B, 높음·낮음 → C. 모두 같으면 "닮았습니다" 카드

## 확인이 필요한 항목

1. **`핸스`** — 성과 지향 '높은 편'의 '책에서 이어지는 것'이 "핸스 뒤에 숨은 부모의 불안"으로 추출됨. PDF 글자 깨짐으로 보이며 원문 확인 필요 (`data/areas.json`)
2. PDF 글자 깨짐을 추정해 고친 단어: 낑낑댈, 꼭 지키는, 몫, 나올 때, 촘촘히, 바뀐다면/바뀌면, 긋는지, 곧바로, 스킨십, 물러섭니다, 들쭉날쭉. 원고와 대조 필요
3. **"먼저 볼 영역" 카드 문구**는 문서에 없어 임시로 작성함 (`copy.json`의 `focusText`)
4. **부부 비교는 URL 방식**이라 문서의 '가족 코드', '배우자 완료 알림(카톡/이메일)', '두 분의 점수는 서로에게만 보입니다'는 구현하지 않음. 문구를 "점수는 서버에 저장되지 않고 링크 안에만 담깁니다"로 바꿈
5. 출간 알림 받기 · 책 구매 링크 · 카카오톡 공유 키는 `config.json`에 값이 들어오면 동작 (지금은 "곧 열립니다" 안내 / 링크 복사)
6. 문항 화면에는 영역 이름을 표시하지 않음 (응답 편향 방지). 질문지처럼 영역 제목을 보여줄지 결정 필요
7. 같은 사람의 6개월 재검사 비교, 파일럿 로그 수집은 아직 범위 밖
